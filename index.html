Installation

From PyPI

# Using pip
pip install deepecgkit

# Using uv
uv pip install deepecgkit

From source

git clone {{ site.kit_repo }}.git
cd deepecg-kit
uv sync --group dev

Version caveat

This page describes the registry exported from deepecgkit {{ ev.registry_kit_version }}{% if ev.registry_kit_git_sha %} at {{ ev.registry_kit_git_sha }}{% endif %}, which registers {{ ev.n_models }} architectures. A release on PyPI may register a different set. The number is read from the export, never typed.

Quick start

See what is registered

deepecg list-models
deepecg list-datasets
deepecg info -m se-resnet

Train one architecture

# PTB-XL, multi-label over 5 diagnostic superclasses
deepecg train -m se-resnet -d ptbxl --multi-label --seed 42

Aggregate finished runs into a snapshot

deepecg aggregate --runs-dir runs --output-dir analysis --emit-latex
deepecg rank --runs-dir runs --metric f1
