<h1>Published results</h1>
<p>Each directory under <code>snapshots/</code> is an immutable published set of results: the raw
output of <code>deepecg aggregate</code> and <code>deepecg rank</code>, a manifest recording exactly
what produced it, the discovery transcript, and SHA-256 checksums.</p>
<p>These files are served verbatim so any number on this site can be traced to a downloadable CSV.
See <a href="{{ '/snapshots/' | relative_url }}">Snapshots</a> for the readable index.</p>
